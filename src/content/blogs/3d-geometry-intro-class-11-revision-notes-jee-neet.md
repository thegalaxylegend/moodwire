## <a id="3d-geometry-fundamentals"></a>**3D Geometry Fundamentals**
* **Point**: Location in 3D space, defined by coordinates.
* **Line**: Set of points extending infinitely in two directions.
* **Plane**: Flat surface, defined by three points.

## <a id="symmetry-and-congruence"></a>**Symmetry and Congruence**
* **Line Symmetry**: $180^\circ$ rotation about a line.
* **Plane Symmetry**: Reflection about a plane.
* **Congruent Shapes**: Identical shapes, with same size and orientation.
* **Similar Shapes**: Same shape, but different sizes.
* Properties of congruent shapes:
  + Same number of sides
  + Same number of angles
  + Same side lengths
  + Same angle measures
* Properties of similar shapes:
  + Same shape
  + Same angle measures
  + Proportional side lengths

## <a id="orthographic-projections"></a>**Orthographic Projections**
* **Isometric View**: $120^\circ$ angle between axes, preserving shape and size.
* **Dimetric View**: $90^\circ$ and $120^\circ$ angles between axes, preserving shape.
* **Trimetric View**: All angles between axes are different, distorting shape.
* **Orthographic Projection**: 2D representation of 3D object, using multiple views.
* Types of orthographic projections:
  + Front view
  + Top view
  + Side view
* Uses of orthographic projections:
  + Technical drawing
  + [architecture](/blog/art-culture-architecture-class-11-revision-notes-jee-neet)
  + Engineering

## <a id="3d-coordinate-systems"></a>**3D Coordinate Systems**
* **Cartesian Coordinates**: $(x, y, z)$, with $x$, $y$, and $z$ axes.
* **Cylindrical Coordinates**: $(r, \theta, z)$, with radial distance $r$ and angle $\theta$.
* **Spherical Coordinates**: $(\rho, \theta, \phi)$, with radial distance $\rho$ and angles $\theta$ and $\phi$.
* Conversion between [coordinate](/blog/coordinate-geometry-class-10-notes) systems:
  + Cartesian to cylindrical: $r = \sqrt{x^2 + y^2}$, $\theta = \tan^{-1}\left(\frac{y}{x}\right)$
  + Cartesian to spherical: $\rho = \sqrt{x^2 + y^2 + z^2}$, $\theta = \tan^{-1}\left(\frac{y}{x}\right)$, $\phi = \cos^{-1}\left(\frac{z}{\rho}\right)$
* Applications of 3D [coordinate](/blog/coordinate-geometry-class-10-notes) systems:
  + [computer](/blog/computer-networks-class-12-notes) graphics
  + Robotics
  + Medical imaging

## <a id="advanced-analysis"></a>Advanced Analysis

* **Curvature**: Measure of how fast a curve turns.
* **Torsion**: Measure of how fast a curve twists.
* **Surface Curvature**: Measure of how curved a surface is.

## <a id="curvature-and-torsion-of-curves"></a>**Curvature and Torsion of Curves**
* Formula for curvature: $k = \frac{||\mathbf{r}'(t) \times \mathbf{r}''(t)||}{||\mathbf{r}'(t)||^3}$
* Formula for torsion: $\tau = \frac{(\mathbf{r}'(t) \times \mathbf{r}''(t)) \cdot \mathbf{r}'''(t)}{||\mathbf{r}'(t) \times \mathbf{r}''(t)||^2}$
* **Frenet-Serret Formulas**: Relate curvature and torsion to curve derivatives.
* **Curve Invariants**: Quantities that remain unchanged under 3D transformations.

## <a id="surface-curvature-and-gaussian-curvature"></a>**Surface Curvature and Gaussian Curvature**
* **Gaussian Curvature**: Measure of how curved a surface is at a point.
* Formula for Gaussian curvature: $K = \frac{eg - f^2}{EG - F^2}$
* **Mean Curvature**: Average of principal curvatures.
* **Principal Curvatures**: Maximum and minimum curvatures at a point.
* **Euler's Formula**: Relates Gaussian curvature to principal curvatures.

## <a id="3d-transformations"></a>**3D Transformations**
* **Rotations**: Preserve length and angle.
* **Translations**: Preserve length and angle, but change position.
* **Scaling**: Changes length, but preserves angle.
* **Affine Transformations**: Combinations of rotations, translations, and scaling.
* **Rigid Body Transformations**: Combinations of rotations and translations.

## <a id="quaternions-and-dual-quaternions"></a>**Quaternions and Dual Quaternions**
* **Quaternion**: Mathematical object with four components.
* Formula for quaternion multiplication: $q_1 \cdot q_2 = (w_1w_2 - \mathbf{v}_1 \cdot \mathbf{v}_2, w_1\mathbf{v}_2 + w_2\mathbf{v}_1 + \mathbf{v}_1 \times \mathbf{v}_2)$
* **Dual Quaternion**: Mathematical object with eight components.
* **Quaternion Applications**: 3D rotations, [computer](/blog/computer-networks-class-12-notes) graphics, and robotics.
* **Dual Quaternion Applications**: 3D transformations, [computer](/blog/computer-networks-class-12-notes) vision, and animation.
