## ⚡ Formula Bank
- $TCP/IPA model has $4$ layers: \text{Application}, \text{Transport}, \text{Internet}, \text{Network Access}$
- OSI model has $7$ layers: $\text{Physical}$, $\text{Data Link}$, $\text{Network}$, $\text{Transport}$, $\text{Session}$, $\text{Presentation}$, $\text{Application}$
- $\text{IP Address}$ is a $32$-bit address in $IPv4$ and $128$-bit address in $IPv6$
- $\text{Subnet Mask}$ is used to determine the scope of the $\text{IP Address}$
- $\text{Gateway}$ is the $\text{IP Address}$ of the router
- HTTP uses $\text{TCP}$ protocol and works on port number $80$
- FTP uses $\text{TCP}$ protocol and works on port number $21$
- TCP is a connection-oriented protocol
- UDP is a connectionless protocol
- $\text{Packet}$ is the basic unit of data transmission
- $\text{Frame}$ is the data unit at the $\text{Data Link Layer}$
- $\text{Segment}$ is the data unit at the $\text{Transport Layer}$
- $\text{Routing}$ is the process of forwarding $\text{Packets}$ between networks
- $\text{Switching}$ is the process of forwarding $\text{Packets}$ within a network
- NATO stands for $\text{Network Address Translation}$
- DHCP stands for $\text{Dynamic Host Configuration Protocol}$
- DNS stands for $\text{Domain Name System}$

- Not understanding the difference between TCP and UDP

## ✏️ 3 Solved PYQs
- **Question 1:** What is the main function of the $\text{Transport Layer}$?
- The $\text{Transport Layer}$ is responsible for providing reliable data transfer between devices
- It ensures that [data](/blog/data-handling-class-8-notes) is delivered in the correct order and that there is no duplication or loss of [data](/blog/data-handling-class-8-notes)
- It also provides flow control and congestion avoidance
- **Answer:** The main function of the $\text{Transport Layer}$ is to provide reliable data transfer between devices
- **Question 2:** What is the difference between a $\text{Router}$ and a $\text{Switch}$?
- A $\text{Router}$ connects multiple networks together and routes $\text{Packets}$ between them
- A $\text{Switch}$ connects multiple devices within a network and forwards $\text{Packets}$ between them
- **Answer:** A $\text{Router}$ connects multiple networks, while a $\text{Switch}$ connects multiple devices within a network
- **Question 3:** What is the purpose of DHCP?
- DHCP is used to assign $\text{IP Addresses}$ to devices on a network
- It eliminates the need for manual $\text{IP Address}$ configuration
- **Answer:** The purpose of DHCP is to assign $\text{IP Addresses}$ to devices on a network

## 📝 Practice MCQs
**1. What is the primary function of the $\text{Network Layer}$?**
-
A) To provide reliable [data](/blog/data-handling-class-8-notes) transfer
-
B) To route $\text{Packets}$ between networks
-
C) To provide flow control and congestion avoidance
-
D) To assign $\text{IP Addresses}$ to devices

**Answer: B) To route $\text{Packets}$ between networks**

**2. Which protocol is used for assigning $\text{IP Addresses}$ to devices on a network?**
-
A) HTTP
-
B) FTP
-
C) DHCP
-
D) DNS

**Answer: C) DHCP**

**3. What is the difference between a $\text{Hub}$ and a $\text{Switch}$?**
-
A) A $\text{Hub}$ connects multiple devices, while a $\text{Switch}$ connects multiple networks
-
B) A $\text{Hub}$ connects multiple networks, while a $\text{Switch}$ connects multiple devices
-
C) A $\text{Hub}$ is a $\text{Router}$, while a $\text{Switch}$ is a $\text{Bridge}$
-
D) A $\text{Hub}$ is a $\text{Bridge}$, while a $\text{Switch}$ is a $\text{Router}$

**Answer: A) A $\text{Hub}$ connects multiple devices, while a $\text{Switch}$ connects multiple devices**

**4. Which layer is responsible for providing reliable data transfer?**
-
A) $\text{Application Layer}$
-
B) $\text{Transport Layer}$
-
C) $\text{Network Layer}$
-
D) $\text{Data Link Layer}$

**Answer: B) $\text{Transport Layer}$**

**5. What is the purpose of $\text{NAT}$?**
-
A) To assign $\text{IP Addresses}$ to devices on a network
-
B) To route $\text{Packets}$ between networks
-
C) To provide reliable data transfer
-
D) To allow multiple devices to share a single $\text{IP Address}$

**Answer: D) To allow multiple devices to share a single $\text{IP Address}$**
