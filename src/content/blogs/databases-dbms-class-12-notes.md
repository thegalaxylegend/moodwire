## ⚡ Formula Bank
A **Database Management System (DBMS)** is a software that allows for the definition, creation, maintenance, and manipulation of databases. It serves as an intermediary between the user and the database, providing a systematic approach to manage and interact with the data.

The main components of a DBMS include:
- **Hardware**: The physical devices that store and process the data.
- **Software**: The DBMS itself, which manages the data and provides services to the users.
- **Data**: The actual information stored in the database.
- **Users**: The individuals who interact with the database through the DBMS.

Some key concepts in DBMS include:
- **Data Definition Language (DDL)**: Used to define the structure of the database.
- **Data Manipulation Language (DML)**: Used to perform operations such as insertion, deletion, and modification of data.
- **Data Control Language (DCL)**: Used to control access to the database.

The advantages of using a DBMS include:
- **Improved data integrity**: By minimizing data redundancy and dependency.
- **Improved data security**: By providing access control and authentication mechanisms.
- **Improved data sharing**: By allowing multiple users to access the data simultaneously.

## ✏️ 3 Solved PYQs
Here are three solved previous year questions to help you understand the exam pattern and practice your problem-solving skills:
1. **What is the primary function of a DBMS?**
   - Answer: The primary function of a DBMS is to manage and interact with the data stored in the database.
2. **Explain the difference between DDL and DML.**
   - Answer: DDL is used to define the structure of the database, while DML is used to perform operations such as insertion, deletion, and modification of data.
3. **What is the purpose of indexing in a database?**
   - Answer: The purpose of indexing is to improve the speed of data retrieval by providing a quick way to locate specific data.

## 🧠 The One Thing Most Students Get Wrong
One common misconception among students is that a DBMS is only used for storing and retrieving data. However, a DBMS provides a wide range of services, including:
- **Data security**: Controlling access to the data and ensuring that it is not compromised.
- **Data integrity**: Ensuring that the data is consistent and accurate.
- **Data sharing**: Allowing multiple users to access the data simultaneously.
