## 🧠 The One Thing Most Students Get Wrong
- Not understanding the difference between rational and irrational numbers.
- Rational numbers can be expressed as $\frac{p}{q}$, where $p$ and $q$ are integers and $q$ 
eq 0$.$
- Irrational numbers cannot be expressed as $\frac{p}{q}$, where $p$ and $q$ are integers and $q$ 
eq 0$.$
- Example: $\sqrt{4}$ is rational because it can be expressed as $\frac{2}{1}$, but $\sqrt{2}$ is irrational because it cannot be expressed as a fraction.

## 📝 Practice MCQs
**1. What is the value of $\sqrt{16}$?**
-
A) $4$
-
B) $-4$
-
C) $2$
-
D) $-2$

**Answer: A) $4$ because $\sqrt{16} = \sqrt{4 \times 4} = 4$.**

**2. What is the value of $\frac{2 + \sqrt{3}}{2 - \sqrt{3}}$?**
-
A) $7 + 4\sqrt{3}$
-
B) $7 - 4\sqrt{3}$
-
C) $2 + \sqrt{3}$
-
D) $2 - \sqrt{3}$

**Answer: A) $7 + 4\sqrt{3}$ because $\frac{2 + \sqrt{3}}{2 - \sqrt{3}} = \frac{(2 + \sqrt{3})(2 + \sqrt{3})}{(2 - \sqrt{3})(2 + \sqrt{3})} = \frac{4 + 4\sqrt{3} + 3}{4 - 3} = \frac{7 + 4\sqrt{3}}{1} = 7 + 4\sqrt{3}$.**

**3. What is the value of $x$ in $\sqrt{x} - \sqrt{3} = \sqrt{2}$?**
-
A) $5 + 2\sqrt{6}$
-
B) $5 - 2\sqrt{6}$
-
C) $2 + \sqrt{3}$
-
D) $2 - \sqrt{3}$

**Answer: A) $5 + 2\sqrt{6}$ because $\sqrt{x} - \sqrt{3} = \sqrt{2}$, $\sqrt{x} = \sqrt{2} + \sqrt{3}$, $(\sqrt{x})^2 = (\sqrt{2} + \sqrt{3})^2$, $x = 2 + 2\sqrt{6} + 3$, $x = 5 + 2\sqrt{6}$.**

**4. What is the value of $\frac{3 + \sqrt{5}}{3 - \sqrt{5}}$?**
-
A) $\frac{7}{2} + \frac{3}{2}\sqrt{5}$
-
B) $\frac{7}{2} - \frac{3}{2}\sqrt{5}$
-
C) $2 + \sqrt{3}$
-
D) $2 - \sqrt{3}$

**Answer: A) $\frac{7}{2} + \frac{3}{2}\sqrt{5}$ because $\frac{3 + \sqrt{5}}{3 - \sqrt{5}} = \frac{(3 + \sqrt{5})(3 + \sqrt{5})}{(3 - \sqrt{5})(3 + \sqrt{5})} = \frac{9 + 6\sqrt{5} + 5}{9 - 5} = \frac{14 + 6\sqrt{5}}{4} = \frac{7}{2} + \frac{3}{2}\sqrt{5}$.**

**5. What is the value of $(\sqrt{2} + \sqrt{3})^2$?**
-
A) $5 + 2\sqrt{6}$
-
B) $5 - 2\sqrt{6}$
-
C) $2 + \sqrt{3}$
-
D) $2 - \sqrt{3}$

**Answer: A) $5 + 2\sqrt{6}$ because $(\sqrt{2} + \sqrt{3})^2 = 2 + 2\sqrt{6} + 3 = 5 + 2\sqrt{6}$.**
