## <a id="-3-solved-pyqs"></a>✏️ 3 Solved PYQs

- **Q1:** If $\tan^2{x} - 2\tan{x} + 1 = 0$, then what is the value of $x$ in the interval $[0, 2\pi]$?
 - **Trap:** Students often confuse this equation with a quadratic equation and try to solve it using the quadratic formula, which is not necessary.
 - **Solution:** 
 The equation can be rewritten as $(\tan{x} - 1)^2 = 0$. 
 Using the property of equality of squares, we get $\tan{x} - 1 = 0$, which simplifies to $\tan{x} = 1$. 
 We know that $\tan{\frac{\pi}{4}} = 1$ and $\tan{\frac{5\pi}{4}} = 1$. 
 Therefore, $x = \frac{\pi}{4}$ or $x = \frac{5\pi}{4}$.
 - **Answer:** $\frac{\pi}{4}$ or $\frac{5\pi}{4}$
 - **Q2:** If $\sin^2{x} + \cos^2{x} = 1$ and $\tan{x} = \frac{3}{4}$, then what is the value of $\sin{x}$?
 - **Trap:** Students often forget to use the given information about $\tan{x}$ to find $\sin{x}$.
 - **Solution:** 
 We are given $\tan{x} = \frac{3}{4}$, which means $\frac{\sin{x}}{\cos{x}} = \frac{3}{4}$. 
 Since $\sin^2{x} + \cos^2{x} = 1$, we can rewrite this as $\sin^2{x} + (\frac{4}{3}\sin{x})^2 = 1$. 
 This simplifies to $\sin^2{x} + \frac{16}{9}\sin^2{x} = 1$, or $\frac{25}{9}\sin^2{x} = 1$. 
 Solving for $\sin{x}$ gives $\sin{x} = \pm \frac{3}{5}$. 
 Since $\tan{x}$ is positive, $x$ must be in the first or third quadrant, and $\sin{x}$ must be positive. 
 Therefore, $\sin{x} = \frac{3}{5}$.
 - **Answer:** $\frac{3}{5}$
 - **Q3:** If $\cos{x} = \frac{1}{2}$ and $x$ is in the fourth quadrant, then what is the value of $\tan{x}$?
 - **Trap:** Students often forget that $\tan{x}$ is negative in the fourth quadrant.
 - **Solution:** 
 Since $\cos{x} = \frac{1}{2}$ and $x$ is in the fourth quadrant, we can find $\sin{x}$ using the identity $\sin^2{x} + \cos^2{x} = 1$. 
 This gives $\sin^2{x} = 1 - \frac{1}{4} = \frac{3}{4}$, or $\sin{x} = \pm \frac{\sqrt{3}}{2}$. 
 Since $x$ is in the fourth quadrant, $\sin{x}$ must be negative, so $\sin{x} = -\frac{\sqrt{3}}{2}$. 
 Therefore, $\tan{x} = \frac{\sin{x}}{\cos{x}} = \frac{-\frac{\sqrt{3}}{2}}{\frac{1}{2}} = -\sqrt{3}$.
