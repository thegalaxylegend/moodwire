## Introduction to Trigonometric Functions are a set of functions that relate the ratios of the sides of a right-angled triangle to its angles. These functions are used to describe the relationships between the sides and angles of triangles and are essential in various fields such as physics, engineering, and navigation. The six basic trigonometric functions are sine, cosine, tangent, cosecant, secant, and cotangent.

## Definition and Basic Concepts
The trigonometric functions are defined as follows:
- Sine: $\\sin(\theta) = \frac{opposite}{hypotenuse}$
- Cosine: $\\cos(\theta) = \frac{adjacent}{hypotenuse}$
- Tangent: $tan(\theta) = \frac{opposite}{adjacent}$
- Cosecant: $csc(\theta) = \frac{hypotenuse}{opposite}$
- Secant: $sec(\theta) = \frac{hypotenuse}{adjacent}$
- Cotangent: $cot(\theta) = \frac{adjacent}{opposite}$

These functions can be represented graphically, with the x-axis representing the angle and the y-axis representing the value of the function. The graphs of these functions are periodic, with a period of $2\pi$ for sine and cosine, and $\pi$ for tangent and cotangent.

## Trigonometric Identities are equations that relate the trigonometric functions to each other. Some of the most important trigonometric identities include:
- Pythagorean identity: $\\sin^2(\theta) + \\cos^2(\theta) = 1$
- Sum and difference formulas:
  -  in(a+b) = \\sin(a)\\cos(b) + \\cos(a)\\sin(b) 
  -  in(a-b) = \\sin(a)\\cos(b) - \\cos(a)\\sin(b) 
  -  os(a+b) = \\cos(a)\\cos(b) - \\sin(a)\\sin(b) 
  -  os(a-b) = \\cos(a)\\cos(b) + \\sin(a)\\sin(b) 
- Double angle formulas:
  -  in(2\theta) = 2\\sin(\theta)\\cos(\theta) 
  -  os(2\theta) = 2\\cos^2(\theta) - 1 = 1 - 2\\sin^2(\theta) 
- Half angle formulas:
  -  in($\frac{\theta}${2}) = \pm $\sqrt{\frac{1-\\cos(\theta)}${2}} 
  -  os($\frac{\theta}${2}) = \pm $\sqrt{\frac{1+\\cos(\theta)}${2}} 

## Trigonometric Equations are equations that involve trigonometric functions. These equations can be solved using various techniques, including:
- Factoring: $\\sin(\theta) = 0$ can be factored as $\\sin(\theta) = 0 \Rightarrow \theta = k\pi$, where $k$ is an integer.
- Using trigonometric identities: $\\sin(2\theta) = 2\\sin(\theta)\\cos(\theta)$ can be used to simplify equations involving $\\sin(2\theta)$.
- Using inverse trigonometric functions: $\\sin(\theta) = \frac{1}{2}$ can be solved using the inverse sine function: $\theta = \\\\sin^{-1}(\frac{1}{2})$.

## Inverse Trigonometric Functions
Inverse trigonometric functions are functions that "reverse" the trigonometric functions. The inverse trigonometric functions are:
- Inverse sine: $\\\\sin^{-1}(x) = \theta \Rightarrow \\sin(\theta) = x$
- Inverse cosine: $\\cos^{-1}(x) = \theta \Rightarrow \\cos(\theta) = x$
- Inverse tangent: $tan^{-1}(x) = \theta \Rightarrow tan(\theta) = x$

These functions can be used to solve trigonometric equations and are essential in various applications, including [physics](/blog/physics-heat-light-class-11-revision-notes-jee-neet) and engineering.

## Solved High-Yield Questions
### Question 1
If $\\sin(\theta) = \frac{1}{2}$, what is the value of $\\cos(\theta)$?

Solution:
Using the Pythagorean identity, we have:
 \\sin^2(\theta) + \\cos^2(\theta) = 1 
Substituting $\\sin(\theta) = \frac{1}{2}$, we get:
 \left(\frac{1}{2}\r\r\right)^2 + \\cos^2(\theta) = 1 
Simplifying, we get:
 \\cos^2(\theta) = 1 - \frac{1}{4} = \frac{3}{4} 
Taking the square root of both sides, we get:
 \\cos(\theta) = \pm \sqrt{\frac{3}{4}} = \pm \frac{\sqrt{3}}{2} 
Since $\\cos(\theta)$ is positive in the first quadrant, we take the positive value:
 \\cos(\theta) = \frac{\sqrt{3}}{2} 

### Question 2
If $tan(\theta) = 2$, what is the value of $\\sin(\theta)$?

Solution:
Using the definition of tangent, we have:
 tan(\theta) = \frac{\\sin(\theta)}{\\cos(\theta)} 
Substituting $tan(\theta) = 2$, we get:
 2 = \frac{\\sin(\theta)}{\\cos(\theta)} 
Cross-multiplying, we get:
 2\\cos(\theta) = \\sin(\theta) 
Squaring both sides, we get:
 4\\cos^2(\theta) = \\sin^2(\theta) 
Using the Pythagorean identity, we have:
 \\sin^2(\theta) + \\cos^2(\theta) = 1 
Substituting $\\sin^2(\theta) = 4\\cos^2(\theta)$, we get:
 4\\cos^2(\theta) + \\cos^2(\theta) = 1 
Simplifying, we get:
 5\\cos^2(\theta) = 1 
Dividing both sides by 5, we get:
 \\cos^2(\theta) = \frac{1}{5} 
Taking the square root of both sides, we get:
 \\cos(\theta) = \pm \sqrt{\frac{1}{5}} = \pm \frac{1}{\sqrt{5}} 
Since $\\cos(\theta)$ is positive in the first quadrant, we take the positive value:
 \\cos(\theta) = \frac{1}{\sqrt{5}} 
Substituting this value back into the equation $2\\cos(\theta) = \\sin(\theta)$, we get:
 2 \cdot \frac{1}{\sqrt{5}} = \\sin(\theta) 
Simplifying, we get:
 \\sin(\theta) = \frac{2}{\sqrt{5}} 

### Question 3
If $\\cos(\theta) = \frac{1}{2}$, what is the value of $tan(\theta)$?

Solution:
Using the definition of tangent, we have:
 tan(\theta) = \frac{\\sin(\theta)}{\\cos(\theta)} 
Substituting $\\cos(\theta) = \frac{1}{2}$, we get:
 tan(\theta) = \frac{\\sin(\theta)}{\frac{1}{2}} = 2\\sin(\theta) 
Using the Pythagorean identity, we have:
 \\sin^2(\theta) + \\cos^2(\theta) = 1 
Substituting $\\cos(\theta) = \frac{1}{2}$, we get:
 \\sin^2(\theta) + \left(\frac{1}{2}\r\r\right)^2 = 1 
Simplifying, we get:
 \\sin^2(\theta) = 1 - \frac{1}{4} = \frac{3}{4} 
Taking the square root of both sides, we get:
 \\sin(\theta) = \pm \sqrt{\frac{3}{4}} = \pm \frac{\sqrt{3}}{2} 
Since $\\sin(\theta)$ is positive in the first quadrant, we take the positive value:
 \\sin(\theta) = \frac{\sqrt{3}}{2} 
Substituting this value back into the equation $tan(\theta) = 2\\sin(\theta)$, we get:
 tan(\theta) = 2 \cdot \frac{\sqrt{3}}{2} = \sqrt{3}
