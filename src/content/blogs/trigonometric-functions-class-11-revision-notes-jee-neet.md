 * *Let's begin.*### Fundamental Identities & Quadrant Rules

- **Reciprocal Identities:**
 - sinθ = 1/cosecθ — θ is the angle
 - cosθ = 1/secθ — θ is the angle
 - tanθ = 1/cotθ — θ is the angle
 - tanθ = sinθ/cosθ — θ is the angle
 - cotθ = cosθ/sinθ — θ is the angle

- **Pythagorean Identities:**
 - sin²θ + cos²θ = 1 — sin²θ = 1 - cos²θ and cos²θ = 1 - sin²θ
 - 1 + tan²θ = sec²θ — tan²θ = sec²θ - 1
 - 1 + cot²θ = cosec²θ — cot²θ = cosec²θ - 1

- **ASTC Quadrant Rule (Signage):**
 - Quadrant I (0 to π/2): All (sin, cos, tan, cosec, sec, cot) are positive
 - Quadrant II (π/2 to π): sin and cosec are positive; others are negative
 - Quadrant III (π to 3π/2): tan and cot are positive; others are negative
 - Quadrant IV (3π/2 to 2π): cos and sec are positive; others are negative

- **Allied Angle Transformations (Reduction):**
 - sin(π/2 - θ) = cosθ — conversion from co-function
 - cos(π/2 - θ) = sinθ — conversion from co-function
 - tan(π/2 - θ) = cotθ — conversion from co-function
 - sin(π - θ) = sinθ — same function, Quadrant II
 - cos(π - θ) = -cosθ — same function, Quadrant II
 - tan(π - θ) = -tanθ — same function, Quadrant II
 - sin(π + θ) = -sinθ — same function, Quadrant III
 - cos(π + θ) = -cosθ — same function, Quadrant III
 - tan(π + θ) = tanθ — same function, Quadrant III
 - sin(2π - θ) = -sinθ — same function, Quadrant IV
 - cos(2π - θ) = cosθ — same function, Quadrant IV
 - tan(2π - θ) = -tanθ — same function, Quadrant IV

- **Even/Odd Identities:**
 - sin(-θ) = -sinθ — odd function
 - cos(-θ) = cosθ — even function
 - tan(-θ) = -tanθ — odd function

**Examiner's Trap:** When using (π/2 ± θ) or (3π/2 ± θ), the function changes to its co-function (sin ↔ cos, tan ↔ cot, sec ↔ cosec). When using (π ± θ) or (2π ± θ), the function remains the same. Always check the final quadrant to assign the ± sign.

### <a id="angle-conversions-and-periodicity"></a>Angle Conversions & Periodicity

- **Degree to Radian Conversion:** Radian = Degree × (π/180) — conversion factor

- **Radian to Degree Conversion:** Degree = Radian × (180/π) — conversion factor

- **Arc Length Formula:** s = rθ — s is arc length, r is radius, θ is angle in radians

- **Periodicity of sinθ and cosθ:** T = 2π — θ is the angle

- **Periodicity of tanθ and cotθ:** T = π — θ is the angle

- **Periodicity of secθ and cosecθ:** T = 2π — θ is the angle

- **General Period for sin(ax + b):** T = 2π/|a| — a is the coefficient of x

**Examiner's Trap:** Students often forget that the periodicity of tan(ax) is π/|a|, not 2π/|a|. In JEE, they will give you a composite function like sin(3x/2) and ask for the period; always divide 2π by the coefficient of x.

### <a id="compound-angle-formulas-sum-and-difference"></a>Compound Angle Formulas (Sum & Difference)

- **Sine Sum/Difference:**
 - sin(α + β) = sinα cosβ + cosα sinβ
 - sin(α - β) = sinα cosβ - cosα sinβ

- **Cosine Sum/Difference:**
 - cos(α + β) = cosα cosβ - sinα sinβ — Note the sign flip
 - cos(α - β) = cosα cosβ + sinα sinβ — Note the sign flip

- **Tangent Sum/Difference:**
 - tan(α + β) = (tanα + tanβ) / (1 - tanα tanβ)
 - tan(α - β) = (tanα - tanβ) / (1 + tanα tanβ)

- **Cotangent Sum/Difference:**
 - cot(α + β) = (cotα cotβ - 1) / (cotβ + cotα)
 - cot(α - β) = (cotα cotβ + 1) / (cotα - cotβ)

**Examiner's Trap:** The cosine sum formula cos(α + β) uses a MINUS sign, and the cosine difference formula cos(α - β) uses a PLUS sign. This is the most common error in high-speed calculations.

### <a id="multiple-and-submultiple-angle-formulas-the-core"></a>Multiple & Sub-multiple Angle Formulas (The Core)

- **Double Angle Formulas (2θ):**
 - sin 2θ = 2 sinθ cosθ
 - sin 2θ = 2 tanθ / (1 + tan²θ) — High-yield JEE shortcut
 - cos 2θ = cos²θ - sin²θ
 - cos 2θ = 2 cos²θ - 1
 - cos 2θ = 1 - 2 sin²θ
 - cos 2θ = 1 / (sec²θ) - 1 / (cosec²θ)
 - tan 2θ = 2 tanθ / (1 - tan²θ)

- **Triple Angle Formulas (3θ):**
 - sin 3θ = 3 sinθ - 4 sin³θ
 - cos 3θ = 4 cos³θ - 3 cosθ
 - tan 3θ = (3 tanθ - tan³θ) / (1 - 3 tan²θ)

- **Half Angle Formulas (θ/2):**
 - sin²(θ/2) = (1 - cosθ) / 2
 - cos²(θ/2) = (1 + cosθ) / 2
 - tan(θ/2) = (1 - cosθ) / sinθ = sinθ / (1 + cosθ)
 - tan(θ/2) = ±√[(1 - cosθ) / (1 + cosθ)]

**Examiner's Trap:** In JEE Advanced, you will often see expressions like √(1 + cosθ). Do not just write 2 cos(θ/2). You must check the quadrant of θ/2 to determine if the result is + or -.

### <a id="transformation-formulas-product-sumdifference"></a>Transformation Formulas (Product ↔ Sum/Difference)

- **Product to Sum/Difference (Transforming multiplication to addition):**
 - 2 sinα cosβ = sin(α + β) + sin(α - β)
 - 2 cosα sinβ = sin(α + β) - sin(α - β)
 - 2 cosα cosβ = cos(α + β) + cos(α - β)
 - 2 sinα sinβ = cos(α - β) - cos(α + β) — Note the order (α-β) first

- **Sum/Difference to Product (Transforming addition to multiplication):**
 - sinC + sinD = 2 sin((C + D)/2) cos((C - D)/2)
 - sinC - sinD = 2 cos((C + D)/2) sin((C - D)/2)
 - cosC + cosD = 2 cos((C + D)/2) cos((C - D)/2)
 - cosC - cosD = -2 sin((C + D)/2) sin((C - D)/2) — Or 2 sin((C + D)/2) sin((D - C)/2)

**Examiner's Trap:** In the "cosC - cosD" formula, the order of the subtraction inside the sine function is critical. If you use (C-D)/2, you must add a negative sign.

### <a id="summation-of-trigonometric-series-jee-advanced-special"></a>Summation of Trigonometric Series (JEE Advanced Special)

- **Sine Series with Angles in Arithmetic Progression (AP):**
 - Σ sin(α + (n-1)β) = [sin(nβ/2) / sin(β/2)] × sin[α + (n-1)β/2]
 - Where and is the number of terms, α is the first angle, and β is the common difference.

- **Cosine Series with Angles in AP:**
 - Σ cos(α + (n-1)β) = [sin(nβ/2) / sin(β/2)] × cos[α + (n-1)β/2]

- **Product of Cosines in AP (Special Case):**
 - cosθ · cos 2θ · cos 4θ · ... · cos(2ⁿ⁻¹θ) = sin(2ⁿθ) / (2ⁿ sinθ)

**Examiner's Trap:** In the series summation, the denominator is always sin(β/2). If the common difference β is 0, the formula fails and you must use simple multiplication.

### <a id="conditional-identities-"></a>Conditional Identities (α + β + γ = π)

- **If α + β + γ = π (Triangle Case):**
 - sin 2α + sin 2β + sin 2γ = 4 sinα sinβ sinγ
 - cos 2α + cos 2β + cos 2γ = -1 - 4 cosα cosβ cosγ
 - sin α + sin β + sin γ = 4 cos(α/2) cos(β/2) cos(γ/2)
 - cos α + cos β + cos γ = 1 + 4 sin(α/2) sin(β/2) sin(γ/2)
 - tan α + tan β + tan γ = tan α tan β tan γ — (Very common in JEE)

- **If α + β + γ = π/2:**
 - tan α tan β + tan β tan γ + tan γ tan α = 1
 - sin 2α + sin 2β + sin 2γ = 4 cosα cosβ cosγ

**Examiner's Trap:** Always verify if the condition is α + β + γ = π or α + β + γ = π/2. The identities for tan and sin change completely between these two conditions.

### <a id="maximum-and-minimum-values-optimization"></a>Maximum & Minimum Values (Optimization)

- **Linear Combination of Sin and Cos:**
 - For the expression f(θ) = a sinθ + b cosθ:
 - Maximum Value = √(a² + b²)
 - Minimum Value = -√(a² + b²)

- **For the expression f(θ) = a sin²θ + b cos²θ:**
 - Maximum Value = max(a, b)
 - Minimum Value = min(a, b)

- **For the expression f(θ) = a sinθ cosθ:**
 - Since sinθ cosθ = 1/2 sin 2θ, the Max/Min is ±a/2.

**Examiner's Trap:** When finding the Max/Min of a function like a sin²θ + b sinθ cosθ + c cos²θ, you MUST convert everything into sin 2θ and cos 2θ first using the double angle formulas.

### <a id="general-solutions-trigonometric-equations"></a>General Solutions (Trigonometric Equations)

- **If sinθ = sinα:**
 - θ = nπ + (-1)ⁿ α, where n ∈ Z

- **If cosθ = cosα:**
 - θ = 2nπ ± α, where n ∈ Z

- **If tanθ = tanα:**
 - θ = nπ + α, where n ∈ Z

- **If sin²θ = sin²α (or cos²θ = cos²α, or tan²θ = tan²α):**
 - θ = nπ ± α, where n ∈ Z

**Examiner's Trap:** In "Find the number of solutions" questions, always check the given interval (e.g., [0, 2π]). Students often find the general solution but fail to count only the values that fall within the specified range.
