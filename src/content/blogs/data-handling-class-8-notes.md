## ⚡ Formula Bank
- Mean = (Sum of all values)/(Total number of values)
- Median = Middle value of the data when arranged ∈ ascending order
- Mode = Value that occurs most frequently ∈ the data
- Range = (Maximum value) - (Minimum value)
- Upper limit of a class = (Upper class limit) + (Class size)/2
- Lower limit of a class = (Lower class limit) - (Class size)/2
- Class mark = (Upper limit + Lower limit)/2
- Frequency = Number of times a value occurs ∈ the data
- Cumulative frequency = Sum of all frequencies up to a certa∈ value

## 🪤 The 5 Mistakes That Cost Marks
- Not arranging the data ∈ ascending order before finding the median
- Not considering the class size while finding the class mark
- Confusing the upper and lower limits of a class
- Not using the correct formula for finding the mean
- Not considering all the values ∈ the data while finding the range

## ✏️ 3 Solved PYQs
- **Question 1:** Find the mean of the [numbers](/blog/rational-numbers-class-8-notes) 2, 4, 6, 8, 10.
  Step 1: Find the sum of all values: 2 + 4 + 6 + 8 + 10 = 30
  Step 2: Find the total number of values: 5
  Step 3: Find the mean: Mean = (Sum of all values)/(Total number of values) = 30/5 = 6
- **Question 2:** Find the median of the numbers 1, 3, 5, 7, 9.
  Step 1: Arrange the data ∈ ascending order: 1, 3, 5, 7, 9
  Step 2: Find the middle value: 5
- **Question 3:** Find the mode of the numbers 2, 2, 3, 3, 3, 4, 4, 4, 4.
  Step 1: Find the frequency of each value: 2 occurs 2 times, 3 occurs 3 times, 4 occurs 4 times
  Step 2: Find the value with the highest frequency: 4

## 🧠 The One Thing Most Students Get Wrong
- Most students get the concept of class limits and class marks wrong. They often confuse the upper and lower limits of a class, which can lead to incorrect calculations.

## 👁️ Ayush's Note
- To find the class mark, use the formula: Class mark = (Upper limit + Lower limit)/2
- To find the cumulative frequency, add up all the frequencies up to a certa∈ value.
- Use a frequency distribution table to organize the data and make calculations easier.

## 📝 Practice MCQs
**1. What is the mean of the numbers 1, 2, 3, 4, 5?**
-
A) 2
-
B) 3
-
C) 4
-
D) 5

**Answer: B) 3. Explanation: Mean = (Sum of all values)/(Total number of values) = (1 + 2 + 3 + 4 + 5)/5 = 15/5 = 3**

**2. What is the median of the numbers 2, 4, 6, 8, 10?**
-
A) 4
-
B) 6
-
C) 8
-
D) 10

**Answer: B) 6. Explanation: Arrange the data ∈ ascending order: 2, 4, 6, 8, 10. Find the middle value: 6**

**3. What is the mode of the numbers 1, 1, 2, 2, 2, 3, 3, 3, 3?**
-
A) 1
-
B) 2
-
C) 3
-
D) 4

**Answer: C) 3. Explanation: Find the frequency of each value: 1 occurs 2 times, 2 occurs 3 times, 3 occurs 4 times. Find the value with the highest frequency: 3**

**4. What is the range of the numbers 1, 2, 3, 4, 5?**
-
A) 4
-
B) 5
-
C) 6
-
D) 7

**Answer: A) 4. Explanation: Range = (Maximum value) - (Minimum value) = 5 - 1 = 4**

-
B) 15
-
C) 20
-
D) 25

**Answer: B) 15. Explanation: Class mark = (Upper limit + Lower limit)/2 = (20 + 10)/2 = 30/2 = 15**
