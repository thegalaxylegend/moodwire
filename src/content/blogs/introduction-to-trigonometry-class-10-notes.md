## ⚡ Formula Bank
- s∈θ = opposite side/hypotenuse
- cosθ = adjacent side/hypotenuse
- tanθ = opposite side/adjacent side
- s∈²θ + cos²θ = 1
- secθ = 1/cosθ
- cosecθ = 1/s∈θ
- tanθ = s∈θ/cosθ
- s∈(90° - θ) = cosθ
- cos(90° - θ) = s∈θ
- s∈(θ + 90°) = cosθ
- cos(θ + 90°) = -s∈θ
